# MakerCrafter

**An open-source project notebook for makers.**

MakerCrafter is where a project comes together *before* it goes to Cricut Design Space,
xTool Studio, LightBurn, or your slicer: ideas, reference images, fonts, colors,
materials, machine settings, and build steps, all in one printable notebook.

- **Any device:** iPhone, iPad, Mac, and PC
- **Your data, your choice:** local-first, synced through your own cloud or your own server
- **Only what you use:** a small core with optional add-ons for lasers, 3D printing, vinyl, and more
- **Open format:** projects are shared as `.makercrafter` files that any tool can read

MakerCrafter is in early design. Follow along at [makercrafter.org](https://makercrafter.org).
